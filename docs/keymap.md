# Ingot keymap

Default shortcuts of the **Ingot (default)** keymap. Double Shift opens Search Everywhere.
Choose **Alternative** in Settings › Keymap to use the platform's standard editor shortcuts instead.
Any shortcut can be changed in Keymap › Edit Shortcuts.
